# 兼容性与验证范围

## 安装门槛

事实来源：`package.json` 的 `engines` 字段。

| 组件 | 要求 |
|---|---|
| Node.js | `^22.19.0` 或 `>=24.0.0` |
| pnpm | `pnpm@11.7.0`（`packageManager` 字段） |
| DeepSeek Harness | `>=0.2.0-rc.1` |

DSH 引擎没有设置上限，因此“允许安装”不等于“已逐版本验证”。

## 已记录的验证

- `0.2.0-rc.2`：曾用打包桌面端运行集成测试。
- `0.2.1-rc.1`：曾用 npm 安装和真实 launcher 运行集成测试。
- `0.2.1-rc.2`：曾用打包桌面端运行集成测试，记录为 111 项通过、0 项跳过。

其他 `0.2.x`、`0.3.x` 和 `1.x` 版本没有逐一实测记录。低于 `0.2.0-rc.1` 会被 `engines.dsh` 拒绝。

## 功能边界

已实现并有测试覆盖：文本收发、媒体双向处理、引用、登录/退出登录、会话命令、`/stop`、审批卡和提问卡、GUI 配置页、模型与权限选择。

当前明确不在范围内：群聊（协议依据不足）、运行期多账号、主动推送、独立权限体系。已知限制见 [troubleshooting.md](./troubleshooting.md) 和项目的 [不变量说明](./invariants.md)。
